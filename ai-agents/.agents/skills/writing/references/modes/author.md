# Режим author

## Цель

Создай готовый русский текст из фактов, требований или заметок пользователя.

## Порядок работы

1. Определи основного читателя и его задачу.
2. Зафиксируй смысловые инварианты по `../clarity-and-readability.md`, включая
   субъект и авторство каждого значимого действия.
3. Сформулируй один главный вывод, действие или пользу.
4. Выбери минимальную структуру для жанра.
5. Напиши черновик сверху вниз: структура, абзацы, предложения, слова.
6. Выполни контекстную проверку чистоты и читаемости.
7. Сверь каждое утверждение и авторство с исходными данными.
8. Выполни регрессионную проверку смысловых инвариантов.

## Выбор intent

- Обычный текст: используй этот файл без дополнительных authoring references.
- Заголовок или название: прочитай `../headings.md`.
- Кейс, история изменений или нарратив: прочитай `../storytelling.md`.
- Предложение, анонс или продуктовый текст, который должен убедить: прочитай
  `../persuasive.md`.

Если задача сочетает историю и убеждение, сначала построй фактическую арку, затем
проверь пользу, доказательства и следующий шаг.

## Структура по задаче

Не применяй один шаблон ко всем жанрам. Выбирай порядок, который помогает
читателю:

| Задача | Рабочий порядок |
|---|---|
| Сообщить статус | статус -> причина -> влияние -> действие |
| Объяснить проблему | суть -> причина -> последствия -> решение |
| Предложить решение | проблема -> варианты -> рекомендация -> риски |
| Дать инструкцию | когда применять -> шаги -> исключения -> проверка |
| Убедить | задача читателя -> польза -> доказательство -> следующий шаг |

Это ориентиры, а не обязательные заголовки.

## Правила

- Не выдумывай недостающие факты и не усиливай claims.
- Не добавляй секцию без содержания.
- Не начинай с истории вопроса, если читателю сначала нужен вывод.
- Не превращай заметки в формальный документ без запроса.
- Не объясняй процесс написания.
- Сохраняй полезную неопределенность.
- Если критичного факта нет, задай один вопрос или выбери нейтральную
  формулировку.

## Результат

По умолчанию верни один готовый вариант. Несколько вариантов давай только по
запросу или когда задача прямо требует выбора названия или формулировки.
