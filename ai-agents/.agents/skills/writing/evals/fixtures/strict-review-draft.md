# DP AI / итоги

## Общая информация

В рамках направления было реализовано эффективное решение, которое значительно
улучшило работу всех пользователей. Данных об изменении пользовательских
сценариев и метрик качества нет.

Сервис всегда отвечает не дольше 100 мс. При высокой нагрузке ответ может
занимать до 2 секунд. SLA пока не согласован.

## Реализация

Была выполнена интеграция с LLM Proxy и RAG Platform, работающей в production
первой версии, которая использовалась командами, и после этого было принято
решение о продолжении развития системы.

Решение от команды описывает SLO/SLI для API /public/v1/search. Владелец SLO
пока не определен.

## Результат

Несколько продуктов получили удобный общий модуль. Proteus и Helicopter
используют API DP AI. Влияние на latency и трудозатраты не измеряли.

## Вывод

Таким образом, решение значительно повысило эффективность и вывело качество
AI-сценариев на новый уровень.
