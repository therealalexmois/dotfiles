## Задача

Собери мои инженерные достижения за [начало]–[конец] из [разрешенные источники:
daily notes, цели, Jira, git, документация, метрики]. Работай только на чтение.
Не меняй задачи, документы, код или production. Используй только настроенные
доступы. Если имя автора или границы поиска неизвестны, уточни их.

Группируй изменения в истории, а не список коммитов. Для каждой найди проблему,
ограничения, мои решения и реализацию, вклад других, результат, фактическое
использование и получателя пользы. Ищи сложные технические решения,
наблюдаемость, evals, документацию, помощь другим командам и повторное применение.
Для цифр укажи источник, единицы, период, baseline и способ расчета. Не считай
строки кода, число задач или tool calls доказательством бизнес-эффекта.

## Критерии готовности

Компактный Markdown с историями по [разделам выбранного шаблона]. У каждого
существенного утверждения есть проверяемый источник или явная пометка, что
оно требует подтверждения. Указаны даты, авторство и статус; старые результаты
не присвоены периоду, планы не названы завершенными. Нет выдуманных цифр,
причинности и ownership. Пробелы и противоречия перечислены отдельно и кратко.
