# Адаптер: Workflow

Оркестрация субагентов Claude скриптом – для массовой фазы, а не для реализации задач. Запускай только фазу, которую владелец выбрал отдельным пунктом плана: этот выбор и есть явное разрешение. Без выбора фазу делают субагенты или ты сам.

## Когда

- Аудит по зонам (деньги, данные, безопасность, побочные эффекты и т. д.).
- Поиск по всему коду с независимой проверкой каждой находки (найти -> проверить).
- Судейская панель для дизайна.

Уместный масштаб: аудит кодовой базы по 16 зонам, где каждую находку проверяет независимый агент, дал 61 issue.

## Пункт плана

Фаза, число агентов, модель и effort по стадиям (поиск low–medium, проверка high), ожидаемый результат, оценка расхода квоты Claude. Число агентов держи в ориентире размера, который задает описание инструмента Workflow, если владелец его не расширил.

## Скрипт

До написания скрипта загрузи скилл `workflow-authoring`: в нем API и его подводные камни. Профильного ревьюера берет `agentType`.

## Ограничения

- Только агенты Claude: Codex и диалог с владельцем посреди прогона недоступны.
- Агент не видит контекст Team Lead: все, что нужно из профиля (запреты, имена опасных рецептов для поиска без Bash), – в его промпте.
- Агенты подхватывали сообщения пользователя как свою задачу: в промпте пиши, что такие сообщения адресованы координатору.
- Результат фазы – вход для Team Lead: находки проверь выборочно и сведи в issues или задания сам.
