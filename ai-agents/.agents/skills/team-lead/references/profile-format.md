# Формат профиля проекта

Профиль – `<repo>/.agents/team-lead.md`, Markdown в репозитории проекта. В скилле живет все, что от проекта не зависит; в профиле – только отличия проекта и то, чего нет в его `AGENTS.md` и `CLAUDE.md`. Правило проекта профиль не пересказывает, а ссылается на него.

## Разделы

| Раздел | Содержание | Где используется |
| --- | --- | --- |
| `## Параметры` | таблица ключей ниже | план, квота, запуск |
| `## Worktree` | как создать и убрать worktree; разрешена ли встроенная изоляция агентов | волна |
| `## Проверки` | окружение тестов; когда нужен широкий прогон; полный гейт серии и его окружение; действия после вливания | ревью, вливание, конец серии |
| `## Исполнители` | дополнительные аргументы `codex-launch.sh` и `claude-launch.sh` | запуск |
| `## Ревьюеры` | профильные субагенты и области их diff | ревью |
| `## Гейты` | гейты владельца сверх общих | план, вливание |
| `## Вливание` | changelog и его правила | вливание |
| `## Подводные камни` | ловушки окружения проекта: хуки, имена команд под правилами разрешений, лимиты размеров | всегда |

## Ключи `## Параметры`

| Ключ | Смысл |
| --- | --- |
| `base-branch` | основная ветка, в которую вливаются PR |
| `max-sessions` | одновременно работающих инженеров в tmux; причина лимита |
| `codex-model` | модель Codex по умолчанию |
| `codex-floor` | остаток недельной квоты Codex (%), ниже которого новые сессии не запускаются; `--quota-floor` его переопределяет |
| `codex-extra-min` | остаток (%) после ядра, при котором берутся дополнительные задачи |
| `claude-floor` | необязательный: остаток окна 7d Claude (%), ниже которого новые агенты Claude не запускаются |
| `issue-solution-heading` | необязательный: заголовок раздела решения в шаблонах issues проекта для `issue-digest.py` |

## Блоки задания

`scripts/compose-task.py` берет из профиля блоки между маркерами `<!-- team-lead:<имя> -->` и `<!-- /team-lead:<имя> -->` (каждый маркер на своей строке). Во всех блоках подставляются плейсхолдеры `{id}`, `{worktree}`, `{branch}`, `{scratchpad}`; прочие фигурные скобки остаются как есть.

| Блок | Обязателен | Куда встает |
| --- | --- | --- |
| `task-context` | да | начало раздела «Контекст»: проект и где его правила |
| `task-criteria` | нет | в конец «Критериев успеха», пунктами |
| `task-constraints` | нет | в конец «Ограничений», пунктами |
| `report-extra` | нет | в конец образца отчета: дополнительные разделы `##`, например предложенная запись changelog |

Общие для всех проектов части задания (git только на чтение, без коммита и PR, без тихих фолбэков, отчет и описание PR, TDD, порядок работы) живут в `assets/task.md` скилла; в блоки профиля их не копируй.
