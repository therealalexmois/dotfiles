# Карточка гипотез

Используй вертикальную форму, если гипотез одна–три: гипотезы в колонках, поля в
строках. Если гипотез больше трех, переверни таблицу: гипотезы в строках, поля в
колонках, а длинные пороги вынеси в примечания под таблицей.

Не добавляй поля, для которых нет данных. ICE, RICE, целевую аудиторию и оценку
сложности добавляй, только если владелец решения дал оценки.

## Вертикальная форма

| | Г1. [Краткое название] | Г2. [Краткое название] |
|---|---|---|
| Формулировка | Если [X], то [Z] изменится на [N или «N неизвестно, оценим по Y»] для [область], потому что [M] | |
| Опровергающее наблюдение | [что увидим, если гипотеза неверна] | |
| Метрика и источник | [как измеряем, откуда берем данные] | |
| Пороги | Подтверждение: [условие]. Опровержение: [условие]. Серая зона: [диапазон] – по умолчанию [действие] | |
| Guardrails | [что не должно ухудшиться] | |
| Способ проверки | [метод по лестнице доказательности] | |
| Статус | [выдвинута / в проверке / подтверждена / опровергнута / не определена / отклонена: причина] | |
| Доказательность | [мнение / анализ кода и документов / расчет / ручной прогон / контролируемый эксперимент] | |
| Основание | [1–2 предложения: на чем держится статус] | |

## Горизонтальная форма

| ID | Формулировка | Метрика и пороги | Способ проверки | Статус | Доказательность |
|---|---|---|---|---|---|
| Г1 | Если [X], то [Z] изменится на [N], потому что [M] | [метрика]; подтверждение [условие], опровержение [условие] | [метод] | [статус] | [уровень] |

## Трассировка «гипотеза → проверка»

| ID | Где проверяется | Что блокирует |
|---|---|---|
| Г1 | [фаза плана, сценарий, расчет] | [нет / что нужно] |
| Г2 | не проверяется: [причина] | – |
