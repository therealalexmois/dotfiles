When writing or editing Python code, docstrings, or tests, invoke the relevant user-level skill first, unless its content is already loaded in this session:

- `python-conventions` — docstring style (Google style, Russian content) and all test-writing rules. The source of truth for docstrings and tests.
- `python-code-style` — code formatting and readability: vertical spacing (blank lines between logical blocks inside a function body), naming conventions, and import organization. Linters do not enforce vertical spacing, so apply it by hand.
