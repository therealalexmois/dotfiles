Before writing or editing Python code, docstrings, or tests, load `python-code-style`
unless it is already loaded.

Use it as the source of truth for:

- naming, imports, formatting, and vertical spacing;
- Google-style docstrings;
- test-writing rules.

Separate logical blocks inside functions with blank lines. Apply this by hand;
linters do not enforce these boundaries.
