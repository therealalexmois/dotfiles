# Отчет об использовании skills

`scripts/skill-usage-report.py` считает вызовы по локальной истории Claude Code
и Codex. Он читает транскрипты и настройки skills, затем печатает таблицу или JSON.

## Запуск

Из корня репозитория:

```sh
scripts/skill-usage-report.py --days 30
scripts/skill-usage-report.py --days 30 --json
```

Скрипт использует `uv run` и зависимость `pyyaml` из метаданных PEP 723.
Источники:

- Claude: `$CLAUDE_CONFIG_DIR/projects`, по умолчанию `~/.claude/projects`;
- Codex: `$CODEX_HOME/sessions`, по умолчанию `~/.codex/sessions`;
- настройки skills: `ai-agents/.agents/skills/` этого checkout.

Если оба каталога транскриптов отсутствуют, CLI завершится с ошибкой argparse.

## Параметры

| Параметр | Назначение |
| --- | --- |
| `--days N` | Учитывать последние N дней. Без параметра читать доступную историю |
| `--all` | Включить skills с ручным вызовом без зафиксированных активаций |
| `--include-external` | Включить обнаруженные skills вне этого репозитория |
| `--json` | Вывести `periods` и `rows` в JSON |

## Колонки

| Колонка | Источник | Что считается |
| --- | --- | --- |
| `c:/` | Claude | Команда пользователя с последующим meta-сообщением скилла |
| `x:$` | Codex | Блок `<skill>` в сообщении пользователя |
| `c:nm`, `x:nm` | Оба | Вызов после упоминания имени в запросе |
| `c:au`, `x:au` | Оба | Автоматический вызов без упоминания имени |
| `c:ns` | Claude | Вызов из другого скилла |
| `c:sb` | Claude | Вызов из субагента |
| `x:nz` | Codex | Чтение при работе над самим скиллом |
| `desc` | Репозиторий | Длина description после нормализации пробелов |

В настройках ручной вызов задают:

```yaml
# Claude: SKILL.md
disable-model-invocation: true

# Codex: agents/openai.yaml
policy:
  allow_implicit_invocation: false
```

Явная команда `/name` или `$name` остается доступной. Упоминание имени в тексте
и вложенные вызовы могут перестать работать после перехода на ручной вызов.

## Вердикты

Скрипт проверяет условия сверху вниз:

| Вердикт | Условие |
| --- | --- |
| `external` | Скилла нет в каталоге репозитория |
| `mismatch` | Настройки ручного вызова Claude и Codex расходятся |
| `manual` | Ручной вызов уже включен в обеих настройках |
| `keep` | Есть автоматические вызовы |
| `check callers` | Есть вложенные вызовы или вызовы из субагентов Claude |
| `candidate (named)` | Есть только явные вызовы и упоминания имени |
| `candidate` | Нет автоматических, названных и вложенных вызовов |

## Ограничения

- `named` определяется эвристически по имени в запросе. Поэтому `auto` дает
  верхнюю оценку, а не точный счетчик самостоятельных решений модели.
- История Claude ограничена `cleanupPeriodDays`.
- Codex считает первое чтение `SKILL.md` через exec за ход. Другие способы
  чтения могут не попасть в отчет.
- Чтения Codex внутри этого репозитория и чтения файлов, измененных в той же
  сессии, считаются шумом.
- Дубли истории исключаются. Отсутствие вызовов в доступных транскриптах
  не доказывает, что скилл никогда не использовался.

Поля `periods` в JSON и даты над таблицей показывают покрытую историю.
